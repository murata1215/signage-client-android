## 動作フロー
```
[1件目] activeWebViewに直接ロード(従来通り) → 表示+タイマー開始 → nextWebViewに2件目を先読み
[2件目] WebViewスワップ(即表示!) → タイマー開始 → nextWebViewに3件目を先読み
[N件目] WebViewスワップ(即表示!) → ...
[最後]  サブプレイリスト完了 → advanceToNextMain() → メインプレイリストへ復帰
```

## 検証手順
1. firstPageOnlyモード: PDF間の切り替えが即座（2件目以降で黒画面なし）
2. firstPageOnly+見開き: デュアル表示のPDF間も即座に切り替わること
3. allPagesモード: 全ページ表示完了後、次のPDFが即座に表示されること
4. サブプレイリスト完了後、メインプレイリストの次のアイテムへ正常遷移
5. メインプレイリスト側のweb/pdf先読みが退行していないこと

## 制約
- 1件目のPDFは先読み不可（同期直後に即表示のため、従来通りの遅延あり）
